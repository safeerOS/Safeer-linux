# Safeer Browser for Linux 1.0.55 · Safeer Control 2.1.11 · Safeer OS 0.4.13

**Shared space in Safeer Link (Safeer OS 0.4.13, Safeer Control 2.1.11)**
- **Store on another device:** right click a file in Files → *Store on another device …*. The device in Safeer Link with the most free space that can help right now (battery, load, memory) downloads the file itself over an encrypted, pinned connection to this computer and keeps it only if its SHA-256 matches the original. It always keeps at least 2 GB free for itself.
- **You decide about the original:** when the copy is verified, Files tells you on which device and in which folder it is (e.g. *Tablica · Downloads › Safeer Shramba*) and asks whether to delete the original – *Delete original* or *Keep both*. Nothing is ever deleted by itself, and a file that changed in the meantime is never deleted.
- **Low on space?** When less than 10 % (or 5 GB) is left, Files says so and shows the largest files; there is also a new *Largest files* view.
- On the other device the files appear in Safeer Link as *Storage for other devices* (needs Safeer OS 0.5.17 on Android).
- The Safeer Link window now translates the reason "Safeer OS helps on this device".

Safeer Browser 1.0.55 has no changes to the browser itself.

Slovensko: **Skupni prostor:** desni klik na datoteko → *Shrani na drugo napravo …* – naprava z največ prostora, ki ta trenutek sme pomagati, datoteko prenese sama in jo obdrži le, če se vsebina ujema. Ko je kopija preverjena, vidiš, na kateri napravi in v kateri mapi je, in sam izbereš *Izbriši izvirnik* ali *Obdrži oboje*. Ko je prostora malo (manj kot 10 % ali 5 GB), Datoteke to povedo in pokažejo največje datoteke.
