# Safeer Browser for Linux 1.0.120 · Safeer Control 2.1.76 · Safeer OS 0.4.78

**Install programs from the provider you choose.** In Programs, the new *Install apps …* button lists software providers in alphabetical order – Bazaar, Discover, Gear Lever, GNOME Software, Snap Store and Software Manager. Safeer recommends none and nothing is preselected; installed providers simply open.

**You always see what will be installed.** Before anything is installed, Safeer shows exactly which packages (including a runtime the program needs, e.g. the GNOME platform), where they come from, whether the system will ask for a password, the download size and how the program will be updated on this computer – for example that automatic updates are on in the Update Manager, if you turned them on there. Nothing is installed until you confirm.

**Snap in one step.** Linux Mint turns Snap off. *Enable* shows every step – remove Mint's block, install snapd, install Snap Store – and that Snap updates its apps by itself (and how to hold updates).

**Your own sources.** The *Sources* tab lists Flatpak repositories, PPAs and package repositories on this computer. Add a PPA (`ppa:name/ppa`) or a Flatpak repository (`https://…/name.flatpakrepo`) after a confirmation.

**Programs from GitHub.** Search public repositories, filter by type (media, communication, development, …), open their releases and filter files by system – *This computer* first. *Save* stores the file in a folder you choose (Downloads by default), never overwrites anything, downloads only from GitHub over https and checks the file against the SHA-256 that GitHub publishes.
