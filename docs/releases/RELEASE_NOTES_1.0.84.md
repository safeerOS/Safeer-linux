# Safeer Browser for Linux 1.0.84 · Safeer Control 2.1.40 · Safeer OS 0.4.42

## Safeer OS 0.4.42

- **File search finds everything, at once.** Searching for a file used to walk the disk again on every letter you typed, for at most a second and a half, starting at the top of the home folder – a file a few folders deep was never found. Safeer OS now keeps the names of the files in your home folder in memory (built in the background shortly after start, refreshed when it gets old or after Safeer itself creates or moves something) and searches there: instantly and at any depth. Hidden folders, folders with program code and other disks are left out, as before.
- **Search the way you type.** Accents no longer matter (`porocilo` finds "Poročilo"), several words can come in any order (`2024 telekom racun`), and results are ranked: the exact name first, then names that begin with what you typed, then the beginning of a word inside the name; among similar matches, files you changed recently come first. The Files section of Safeer OS shows up to 200 results instead of 60.
- **The same language as the rest of the desktop.** Safeer OS now reads the session language the way other programs do (LANGUAGE, then LC_ALL, LC_MESSAGES, LANG). On a system with the language set to Slovenian and the regional format to another country, Safeer OS was in English while Safeer Control was in Slovenian.

## Safeer Control 2.1.40

- **No window that nobody asked for.** When Safeer OS started and Safeer Control was not running yet, the Safeer Control window (sign-in or devices) opened by itself: Safeer OS started Control twice within a fraction of a second, and the second start made the first one show its window. The same could happen at login when the two start together. Safeer Control now makes sure a single copy runs: a second start in the background ends silently, and starting it from the menu only brings up the window of the one that is running.

Safeer Browser 1.0.84 has no changes of its own (same code, new number).

Slovensko: **Iskanje datotek najde vse, takoj.** Doslej je iskanje ob vsaki vtipkani črki znova hodilo po disku, največ sekundo in pol in od vrha domače mape navzdol – datoteke nekaj map globoko ni našlo nikoli. Safeer OS si zdaj imena datotek v domači mapi zapomni (v ozadju kmalu po zagonu; obnovi jih, ko so stara ali ko Safeer sam kaj ustvari ali premakne) in išče po njih v pomnilniku: takoj in po vsej globini. Skrite mape, mape s programsko kodo in drugi diski ostanejo izpuščeni kot prej. **Iščeš, kakor tipkaš**: šumniki niso več pomembni (`porocilo` najde »Poročilo«), več besed je lahko v poljubnem vrstnem redu (`2024 telekom racun`), zadetki pa so razvrščeni – najprej točno ime, nato imena, ki se začnejo z vtipkanim, nato začetek besede v imenu; med podobnimi so nedavno spremenjene datoteke prej. Razdelek Datoteke pokaže do 200 zadetkov namesto 60. **Isti jezik kot namizje**: Safeer OS bere jezik seje kot drugi programi (LANGUAGE, nato LC_ALL, LC_MESSAGES, LANG); v sistemu s slovenskim jezikom in tujo regijo je bil Safeer OS angleški, Safeer Control pa slovenski. **Safeer Control 2.1.40 – brez okna, ki ga nihče ni naročil**: ko se je Safeer OS zagnal in Control še ni tekel, se je okno Safeer Control (prijava ali naprave) odprlo samo – Safeer OS je Control v delčku sekunde zagnal dvakrat in drugi zagon je prvemu odprl okno; enako se je lahko zgodilo ob prijavi. Control zdaj poskrbi, da teče en sam: drugi zagon v ozadju se konča tiho, zagon iz menija pa samo pokaže okno tistega, ki že teče.
