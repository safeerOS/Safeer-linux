# Safeer Browser for Linux 1.0.123 · Safeer Control 2.1.78 · Safeer OS 0.4.80

**Stremio add-ons as easy as on Android.** Press Install on a Stremio add-on page – in the web panel of Safeer OS or in another browser – and Safeer Player opens Add-ons with the address already filled in. The add-on is checked and added only when you press Connect. If the Stremio app is installed and already opens these links, Safeer leaves that choice alone.

**Paste.** Add-ons has a Paste button: copy the add-on address anywhere and paste it with one click.

**One add-on, once.** The address of the configuration page (…/configure), of the manifest (…/manifest.json) or of the add-on itself is the same add-on – it is never added twice. A new add-on gets the name from its manifest instead of the server address.
