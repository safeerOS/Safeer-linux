# Safeer Browser for Linux 1.0.112 · Safeer Control 2.1.68 · Safeer OS 0.4.70

**Web pages can no longer tell that Safeer has a built-in ad blocker.** One general protection, the same for every site (no per-site rules): checks that use bait elements, fake requests to ad servers or probe scripts get the same answer as without a blocker, so "please turn off your ad blocker" walls do not appear.

Empty bait elements (such as `adsbox`) now stay in the page, hidden with CSS, instead of being deleted. Blocking of ads and threats works as before; YouTube is excluded.
