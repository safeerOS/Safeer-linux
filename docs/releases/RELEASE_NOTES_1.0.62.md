# Safeer Browser for Linux 1.0.62 · Safeer Control 2.1.18 · Safeer OS 0.4.20

**Send to device – the computer as the target (Safeer Control 2.1.18, Safeer OS 0.4.20)**
- Your phone, tablet or TV can now send what it is playing to this computer ("Send to device" in the Android player). A small quiet banner appears in the corner of the screen – "Tablet is sending you: Film (12:34)" with Accept / Decline – and nothing changes until you press Accept; then Safeer OS plays it at the same second (a file from the sending device through its server with a token for this computer, a file of a third device with this computer's own token, this computer's own file straight from disk, or a web stream by its address).
- The banner is Safeer Control's own window, so it works even when desktop notifications are switched off; it disappears after a minute, the offer stays valid for ten.

Safeer Browser 1.0.62 has no changes to the browser itself.

Slovensko: **Pošlji na napravo – računalnik kot cilj.** Telefon, tablica ali televizor pošlje, kar predvaja; v kotu zaslona se pokaže tiha pasica s Sprejmi/Zavrni, nič se ne spremeni do Sprejmi, nato Safeer OS nadaljuje pri isti sekundi. Brskalnik brez sprememb.
