# Safeer Browser for Linux 1.0.125 · Safeer Control 2.1.80 · Safeer OS 0.4.82

**Couch mode.** The Media Center has a Couch mode button: big tiles, a clear selection frame, the window fills the screen. Move with the arrow keys, the remote, your phone or a gamepad (A = OK, B = Back); Back closes the details and returns to the tile you came from. The mouse always works too – move it and the selection follows; keep it still and the pointer hides.

**Safeer Player full screen.** Safeer Player always opens maximised.

**Music in one place.** Music from this computer is part of the Music catalogue (»On this computer«), not a separate section above it.

**Content language.** Choosing a language no longer hides everything: titles in that language come first, titles whose language the source does not tell come after them under »Language unknown«.

**Stremio add-ons, fast.** Add-ons and sources has a »Find Stremio add-ons« button. Press Install on an add-on page and it appears in Safeer – the Stremio app is not needed.

**Built-in sources.** PeerTube and Internet Archive are no longer built in; Jamendo, radio and live TV are. You can still add any source yourself.
