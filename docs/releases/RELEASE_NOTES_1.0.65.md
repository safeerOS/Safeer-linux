# Safeer Browser for Linux 1.0.65 · Safeer Control 2.1.21 · Safeer OS 0.4.23

**Updates with one press (Safeer OS 0.4.23)**
- Safeer OS checks safeer.si itself (quietly, every few hours). When a new version is out, a small note appears on the home screen and Settings gets an **Updates** section: "Available: Safeer OS 0.4.24, Safeer Control 2.1.22" – one press downloads the packages (SHA-256 verified) and installs them: DEB packages through `pkexec apt-get install` (the system asks for your password), Flatpak through `flatpak install --user`, an AppImage replaces itself. The new version starts with the next launch of Safeer OS. Nothing is installed without you.
- The same section says "Up to date (0.4.23)" otherwise and checks again on press.

Safeer Browser 1.0.65 has no changes to the browser itself.
