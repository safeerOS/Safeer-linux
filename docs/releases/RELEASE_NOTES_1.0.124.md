# Safeer Browser for Linux 1.0.124 · Safeer Control 2.1.79 · Safeer OS 0.4.81

**Panels on the desktop.** Hide panel now works on every panel, also the last one. Hidden panels wait as buttons under the search box (Media Center, Files, Programs) – one click brings them back.

**Your folders.** Files on the desktop lists the Desktop folder and the folder bookmarks you have in Nemo, like the usual Linux Mint desktop.

**Music in the Media Center.** Songs from your disk are a song list with title and artist instead of a wall of identical tiles; All shows the first eight. Music add-ons that present songs as films now appear under Music, with the artist.

**Stremio add-ons (from 1.0.123).** Press Install on an add-on page and Safeer Player opens Add-ons with the address filled in; the add-on is added only when you press Connect. Paste button; the same add-on is never added twice.
