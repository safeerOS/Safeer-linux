# Safeer Browser for Linux 1.0.79 · Safeer Control 2.1.35 · Safeer OS 0.4.37

- **Cloud gaming on the Safeer desktop.** Under Apps → Games there is a new tile, GeForce NOW. It is an offer, not an installed program: click it and the menu tells you what it is, whether this computer meets the published requirements, and offers **Install (official NVIDIA package)**. Safeer then adds NVIDIA's own Flatpak source and installs the app for your user – no administrator password, nothing from third parties. After that GeForce NOW is a normal program: one click starts it. You need an NVIDIA account; Safeer does not sell or bundle anything.
- **Nothing is installed until you ask.** Installing Safeer OS does not install GeForce NOW, and the page cannot start an installation by itself – only the menu entry does.
- **You always see where a game runs.** Every tile says it: “This computer”, the name of the device in Safeer Link, or “☁ Cloud · NVIDIA”. A cloud program is listed under Games even if its own menu entry says otherwise.
- **Compatibility is checked honestly.** Safeer checks what it can know (memory, processor, Flatpak, the system). On Linux Mint it says “Worth a try: Linux Mint is not on the official list, but shares its base with the supported Ubuntu 24.04” instead of pretending to know. It does not judge the graphics card: the NVIDIA package brings its own graphics stack, so a verdict from outside would be a guess.
- GeForce NOW is the first entry in a list of cloud-gaming providers (`core/os_oblak_igre.py`); another provider is one more entry, not special code.

Safeer Browser 1.0.79 and Safeer Control 2.1.35 have no changes of their own (same code, new number).

Slovensko: **Igre v oblaku na namizju Safeer** – med Programi → Igre je nova ploščica GeForce NOW. To je ponudba, ne nameščen program: klik pove, kaj je, ali ta računalnik izpolnjuje objavljene zahteve, in ponudi **Namesti (uradni paket NVIDIA)**. Safeer doda uradni NVIDIA vir Flatpak in aplikacijo namesti zate (brez skrbniškega gesla, nič od tretjih). Potem je GeForce NOW navaden program, ki ga zažene en klik; potrebuješ račun NVIDIA. Nič se ne namesti, dokler tega ne zahtevaš. Vsaka ploščica pove, kje igra teče: »Ta računalnik«, ime naprave v Safeer Linku ali »☁ Oblak · NVIDIA«. Združljivost je preverjena pošteno: na Linux Mintu piše »Lahko poskusiš«, ker Mint ni na uradnem seznamu, ima pa isto osnovo kot podprti Ubuntu 24.04; grafične kartice Safeer ne ocenjuje, ker paket NVIDIA prinese svoje gonilnike.
