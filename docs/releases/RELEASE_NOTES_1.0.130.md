# Safeer Browser for Linux 1.0.130 · Safeer OS 0.4.88 (with Safeer Control 2.1.85)

**The address bar is also a search box.** Until now, typing a word such as »test« into the address bar of Splet or Safeer Browser opened https://test/ and showed »This page can't be opened right now«, and even several words were treated as a web address. Now the address bar works like in other modern browsers: words, sentences, version numbers (»python 3.12«) and file names (»invoice.pdf«) are searched with the search engine you chose, while web addresses (»safeer.si«, »github.com/…«, »https://…«), local addresses (»localhost:8080«, »192.168.0.1«) and IP addresses open directly. Start with »?« to search for something that looks like an address (»?safeer.si«).

**Cleaner live results in the magnifier.** The first three web results under »Search the web« are now taken only from a fully loaded results page, so you no longer get just one or two of them; Startpage no longer shows its own click-tracking link as a duplicate result; and the note naming the search engine that received what you typed is shown even when the engine returned nothing.

This is a small release with only these fixes; everything else is the same as in 1.0.129.
