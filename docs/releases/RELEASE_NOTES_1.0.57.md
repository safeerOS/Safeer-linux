# Safeer Browser for Linux 1.0.57 · Safeer Control 2.1.13 · Safeer OS 0.4.15

**Convert a whole folder for TV – proportional share (Safeer OS 0.4.15, Safeer Control 2.1.13)**
- **Convert videos in a folder for TV:** right click a folder in Files → *Convert videos in this folder for TV (1080p) …*. Every video goes to a different device in Safeer Link (phone, tablet, TV), so several convert at the same time; a device that is busy playing video or music is skipped, a fast device gets the next video as soon as it is free, and a video a device cannot read moves to another one. You see progress per device and choose at the end whether to copy the converted videos next to the originals.
- **The computer streams torrents to devices even when its processor is busy** (compiling, Safeer OS in the background) – streaming is network and disk work; only free memory and disk space still decide. Each request is logged in `~/.cache/safeer-control/dnevnik.log`.
- Needs Safeer OS 0.5.19 (or Safeer Predvajalnik 0.2.11) on the Android devices for live transcoding and the signed Link members.

Safeer Browser 1.0.57 has no changes to the browser itself.

Slovensko: **Pretvori videe v mapi za televizor:** desni klik na mapo v Datotekah – vsak video dobi svojo napravo v Safeer Linku (telefon, tablica, televizor), zato jih več pretvarja hkrati; naprava, ki predvaja, je preskočena, hitra naprava dobi naslednji video, video, ki ga naprava ne zna prebrati, gre drugam. **Računalnik pretaka torrente napravam tudi, ko je procesor zaseden** (prevajanje, Safeer OS) – odločata le pomnilnik in prostor.
