# Safeer Browser for Linux 1.0.64 · Safeer Control 2.1.20 · Safeer OS 0.4.22

**Handoff, polished (Safeer Control 2.1.20, Safeer OS 0.4.22)**
- **"Playback for other devices" switch in Safeer OS:** next to "Trust this computer" in the Safeer Link section. Off means other devices cannot ask what this computer is playing, continue it there or send to it; the tray menu item of Safeer Control follows the switch and vice versa.
- **"Continue from another device" in the Media Centre header:** one click opens the list of what your devices are playing or last watched (it is still the first row of the device list as well).
- **Honest feedback from the sender's side:** if the target phone or tablet cannot show a notification (notifications off, or Safeer OS on the TV is in the background), "Send to device" says so – "open Safeer OS there and confirm with Accept" – and the offer waits there.

Safeer Browser 1.0.64 has no changes to the browser itself.
