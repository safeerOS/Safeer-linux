# Safeer Browser for Linux 1.0.80 · Safeer Control 2.1.36 · Safeer OS 0.4.38

- **A film starts with a source that works.** Some add-ons hand out time-limited links and keep serving them after they have expired; the server then refuses them. Such a source used to be tried first. Safeer OS now reads the expiry from the link itself: an expired link goes last, and between two equal sources the permanent link wins – the same rules as Safeer OS for Android 0.5.45.
- **The first source must actually respond.** Before the player starts, the Media Centre asks the three best sources for their first bytes at the same time and starts with the best one that answers. A dead link (deleted, refused, a web page instead of the video) no longer reaches the player.
- **Search on the Safeer Cinnamon desktop: Enter opens the program.** Type a few letters and press Enter: if a program matches, it starts – best match first (the beginning of the name, then the beginning of a word, then the programs you use most). The web search stays the first row and is always Shift+Enter. Enter pressed before the results arrive waits for the list of programs instead of opening the web.

Safeer Browser 1.0.80 and Safeer Control 2.1.36 have no changes of their own (same code, new number).

Slovensko: **Film se začne z virom, ki dela** – nekateri dodatki ponudijo časovno omejene povezave in jih hranijo tudi, ko so že potekle; strežnik jih takrat zavrne. Safeer OS rok zdaj prebere iz same povezave: potekla gre na konec, med enakovrednima viroma ima prednost trajna povezava (ista pravila kot Safeer OS za Android 0.5.45). **Prvi vir mora res odgovoriti**: Medijski center pred začetkom tri najboljše vire hkrati vpraša za prve bajte in začne z najboljšim, ki odgovori – mrtva povezava ne pride več do predvajalnika. **Iskanje na namizju Safeer Cinnamon: Enter odpre program** – če se program ujema, ga Enter zažene (najprej ujemanje na začetku imena, nato na začetku besede, nato programi, ki jih največ uporabljaš); iskanje po spletu ostane prva vrstica in je vedno Shift+Enter. Enter, pritisnjen pred prihodom zadetkov, počaka na seznam programov.
