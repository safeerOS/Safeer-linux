# Safeer Browser for Linux 1.0.60 · Safeer Control 2.1.16 · Safeer OS 0.4.18

**Trust circle tidies itself (Safeer Control 2.1.16)**
- A device that has not been seen for 90 days (for example a phone's old identity after a reinstall) is removed from the trust circle; the removal is signed and applies on all devices.
- Sibling identities of a live device stay (the phone, its browser and its player count as one device), and a hub that was switched off for a while does not remove anyone – it only tidies after it has been running for an hour and has seen the circle recently.
- Contact times are kept next to the circle file (`krog.json-stiki.json`), written at most every 10 minutes.

Safeer Browser 1.0.60 has no changes to the browser itself.
