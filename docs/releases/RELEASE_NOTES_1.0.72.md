# Safeer Browser for Linux 1.0.72 · Safeer Control 2.1.28 · Safeer OS 0.4.30

- **Films from torrent add-ons now play in the Media Centre on the computer.** Until now Safeer OS on the computer played only direct streams; a title that your add-ons offer only as a torrent was hidden as "not available", while Safeer OS for Android played it. Now the computer downloads the torrent and the player starts while it is still downloading – measured: about one second to prepare a well-seeded film, picture a few seconds later. Direct streams keep priority; among torrents the well-seeded one is chosen. Subtitles that come with the torrent are offered in the player.
- **What you only watched does not fill the disk.** A film downloaded just for watching is removed automatically, with its files, once nobody has played it for 48 hours; when there is no room for a new film, the ones nobody has watched for the longest go first. Torrents you added yourself under Magnet links are never touched.
- **The second click no longer waits.** Asking for a film the computer is already downloading – a second click, resuming after a pause, or a second device asking for the same film – could hang for up to 90 seconds, because the torrent engine searched for the film's description again at peers it was already connected to. The description now comes from the engine itself (measured: 0.0 s instead of a hang).
- **Safeer OS and Safeer Control can use torrents at the same time.** Each runs its own torrent engine and both wanted the same port, so the second one stopped right at start ("the magnet program has stopped"). Each engine now gets its own port.
- **A film also starts on a slow disk.** In the first seconds after a torrent is added the engine answered with an error and the player gave up; the stream now waits until the torrent is ready.
- Adding a torrent is faster: the peers found while reading the torrent are handed to the engine instead of being searched for again.

Safeer Browser 1.0.72 has no changes of its own (same code, new number).

Slovensko: filmi, ki jih dodatki ponujajo kot torrent, se zdaj predvajajo tudi v Medijskem centru na računalniku (prej samo na Androidu; na računalniku je bil tak naslov skrit kot »ni na voljo«). Računalnik film prenaša, predvajalnik začne že med prenosom; neposredni tokovi imajo prednost, med torrenti izbere dobro podprtega, podnapisi iz torrenta so v predvajalniku. Kar si samo gledal in tega 48 ur nihče ni predvajal, se odstrani samo; torrentov, ki si jih dodal sam (Magnet povezave), se Safeer ne dotika. Drugi klik na isti film, nadaljevanje po premoru ali druga naprava, ki prosi za isti film, ne čakajo več do 90 sekund. Safeer OS in Safeer Control lahko torrente uporabljata hkrati (prej se je drugi motor ugasnil ob zagonu). Film se začne tudi na počasnem disku.
