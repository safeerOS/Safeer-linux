# Safeer Browser for Linux 1.0.92 · Safeer Control 2.1.48 · Safeer OS 0.4.50

## Safeer OS 0.4.50

- **Programs: a newly installed program appears at once.** A program installed while the workspace was open did not show in the Programs panel until Safeer OS was restarted — although the search at the top found it. The panel and the Programs section read the list of this computer's programs once, when the page loaded. Safeer OS now watches the folders with launchers: a program that is installed or removed appears or disappears about two seconds later, without a restart. Devices in Safeer Link are not asked again for this.

## Packages

- **A published release is final.** The workflow that builds the Linux packages used to run again when a release was published and replaced the packages of the already published release with a fresh build — the same version, but different checksums than the ones verified in the draft. It no longer touches a release that is not a draft.

Safeer Control 2.1.48 and Safeer Browser 1.0.92 have no changes of their own (same code, new number).
