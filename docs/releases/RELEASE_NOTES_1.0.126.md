# Safeer Browser for Linux 1.0.126 · Safeer Control 2.1.81 · Safeer OS 0.4.83

**Dock your way.** Right-click a program on the desktop and choose Add to dock or Remove from dock. Panels menu › Edit dock lists the dock with up/down arrows and a remove button, plus Add a program with search – it works with the remote too. The dock has a clean transparent look (no grey strip at the screen edge).

**Search in the desktop player.** Type in the player on the desktop: the three most likely results appear as soon as they arrive, so Files stays visible. Searching for a radio station shows stations from your country first (»rock radio« → Rock Radio, Radio 1 Rock), and a station with several channels shows them as buttons under the player (Rock Radio: Best Ballads, Hard & Heavy, Classics). The stations' own pages tell Safeer the channels – nothing is typed in by hand.

**Protected video.** Pages that need Widevine (Netflix, Disney+, Max …) open in the Chromium-based browser you already have (Brave, Chrome …), with a short note why. Safeer does not ship or download the Widevine component.

**Tidier desktop.** Unreachable devices are one short line (only when you show programs of all devices); the search box hint is never cut off; bigger search boxes with a magnifier in Files and Programs; Find Stremio add-ons button at the top of the Media Center; 160 % text size option. PeerTube is searched only on servers you add.

**Also in this release (1.0.125):** couch mode in the Media Center (remote, phone, gamepad, mouse), Safeer Player full screen, music from this computer inside the Music catalogue, content language without hiding unknown titles, Stremio add-ons without the Stremio app, PeerTube and Internet Archive not built in.
