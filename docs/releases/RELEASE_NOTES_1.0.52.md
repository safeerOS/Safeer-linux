# Safeer Browser for Linux 1.0.52 · Safeer Control 2.1.8 · Safeer OS 0.4.10

**Safeer Link – devices help each other (Safeer Control 2.1.8)**
- **Your computer streams torrents for the TV.** When a TV (or another weaker device) opens a torrent from a Stremio add-on, the computer downloads it and sends only a live stream to the TV – like Netflix. Nothing is stored on the TV. Downloads go to *Downloads/Safeer/Za naprave*.
- **No overload.** The computer takes on the job only when it has spare processor, memory and disk (always keeps 2 GB free). If it is busy, it says so and the device asks the next computer in your Link.
- **Remove it from the TV.** *Downloads on your computer* in the TV's Video section lists what the computer keeps for your devices; *Remove from computer* deletes the film and its files.
- The stream is protected with the device's token and the computer's pinned certificate; the local torrent engine stays on 127.0.0.1 and has its own state, separate from Safeer OS.

Safeer Browser 1.0.52 and Safeer OS 0.4.10 have no other changes.
