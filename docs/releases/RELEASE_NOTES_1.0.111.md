# Safeer Browser for Linux 1.0.111 · Safeer Control 2.1.67 · Safeer OS 0.4.69

**The counter of blocked ads and threats is gone.** Its display is removed from the start page, the shield button in the toolbar, the shield dialog and the Safeer OS shield tooltip. Blocking of ads and threats works exactly as before; the app just no longer counts and shows how much was blocked.

The internal counting messages from page scripts are still accepted and ignored, so older scripts do not break. The two stored numbers in the settings file are no longer used.
