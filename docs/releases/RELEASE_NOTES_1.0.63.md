# Safeer Browser for Linux 1.0.63 · Safeer Control 2.1.19 · Safeer OS 0.4.21

**The computer as a full partner in handoff (Safeer Control 2.1.19, Safeer OS 0.4.21)**
- **Continue from another device – on the computer:** the Media Centre's device list now starts with "Continue from another device". It asks your Safeer Link devices what they are playing or last watched and lists the offers ("Tablet · Film (12:34) · playing"); "Continue here" plays it on this computer at the same second (a file through the device's server with a token for this computer, a file of a third device with this computer's token, this computer's own file from disk, or a web stream), and for something that is playing right now you can also choose "Continue here and stop there".
- **Send to device – from the computer:** the Safeer OS player has a "Send to device" button; pick a phone, tablet, TV or another computer in Safeer Link and it shows a quiet Accept/Decline prompt there, continuing at the same second only after Accept, while this computer keeps playing.
- **Clear feedback when the target cannot show notifications:** if the target phone or tablet has notifications for Safeer OS switched off, the sender sees "notifications are off there, so open Safeer OS on that device and confirm with Accept"; the offer waits there and appears as a banner when Safeer OS opens.
- Safeer OS remembers which device a file came from, so "last watched" offers for files of other devices work after a restart too.

Safeer Browser 1.0.63 has no changes to the browser itself.
