# Safeer Browser for Linux 1.0.46 · Safeer Control 2.1.2 · Safeer OS 0.4.4

**Safeer OS 0.4.4 – two ways to use it.** `safeer-os` opens Safeer OS as a program in a window. The new **`safeer-os-tema`** package (Linux Mint) makes Safeer OS your desktop: the Safeer-OS theme for GTK, window borders and Cinnamon, and Safeer OS starts full screen when you log in with its own bottom bar. *Return to Linux Mint* in the menu restores your previous look and turns the start-up off.

- **Same side bar on every Safeer OS:** Home, Media center, Safeer Link, Programs, Files, Web, Notes, Settings.
- **Smart search in the top bar:** a web address or question opens in Web, files in Files, programs in Programs, films and music in Media center – also by the name of a web app.
- **Web stays in Safeer:** web search and web apps open in Safeer Browser (brought to the front) or in the built-in view – never in a foreign system browser.
- **Notes:** a new section for quick notes.
- **Programs of other devices** now show their real icons (lists are sent in parts that fit a Safeer Link message).
- **Games from this computer on another screen** (Windows, TV) fill the whole screen, and the keyboard of the other device controls them.
- **Devices:** one device is one entry (TV and Safeer OS, PC and Control are merged), this computer first; *Forget this device* is now *Sign out this device*; pairing with a QR code or a 6-digit code directly in Safeer Control.
- **Remote screen PC ↔ PC:** the mouse lands exactly where you click.
- **Lighter on memory:** tabs you do not look at are frozen after 60 s and released after 10 minutes (sooner when memory runs low), and restored when you come back; the browser saves the session on shutdown and every minute.
- **Safeer Shield:** additional video-ad servers and trackers (list from m6-adblock, MIT).
- **Fix:** Safeer Control on a new install could not join the trust circle (a module was missing from the package) – the device list stayed empty.
