# Safeer Browser for Linux 1.0.93 · Safeer Control 2.1.49 · Safeer OS 0.4.51

## Safeer OS 0.4.51

- **Files refresh by themselves.** The open folder, Recent and Trash now update when *another program* changes them — a download that finishes in the browser, a file copied in the file manager, a file that arrives from another device. Until now a folder was read when it was opened and after your own actions; a new file appeared only after the folder was opened again. A new, deleted or renamed file shows within a second; a file that is still downloading updates its size every few seconds. The selection, the page and the scroll position stay where they were — even deep in a large folder the same rows stay in the same place. This works in the Files panel of the workspace and in the Files section of the Safeer OS window, including the recent files on the home screen.
- **USB sticks and disks appear and disappear by themselves** in the list of places (before: when you returned to Safeer OS, at most every 30 seconds). This part follows the system's own signals; it was not tested with a physical USB stick.
- **Search finds a file you have just downloaded.** The index of file names is rebuilt when it is ten minutes old or when Safeer itself moves a file. A file that another program had just saved — a download in Downloads, a screenshot on the Desktop — was therefore not found for up to ten minutes, although it was visible in the folder. Search now also looks live at the top level of your folders (Home, Desktop, Documents, Downloads, Pictures, Music, Videos) and adds what appeared after the index was built. Deeper in subfolders the index still applies (at most ten minutes).
- **Media centre: content language next to the genre.** `All languages ▾` stands at the start of the genre row for All, Films, Series, Video and Music (in Video, which has no genres, it stands alone). The interface language and English are at the top, the rest in alphabetical order. The language comes from the source itself (PeerTube, Jamendo, public-domain films, radio, the TMDB catalogue); for titles from add-ons that carry an IMDb id Safeer asks Wikidata — a free knowledge base, no key and no account. An entry whose language is not known is not shown while a language is selected, and an empty catalogue says that it is empty *in the selected language*. The choice lasts while Safeer OS is open, like the genre. The same choice exists in Safeer OS for Android 0.5.48, with the same rules and the same 38 languages.
  - What leaves the computer, and only while a language is selected: the public IMDb ids of titles in the catalogue on screen (to Wikidata) and the selected language (to PeerTube, Jamendo and TMDB). Titles from a private add-on are never asked about. Nothing about you, your add-ons or what you watch. Details: `docs/CONTENT-LANGUAGE.md`.
  - Not in this version: titles of a language that none of your sources has (Android lists them from Wikidata for its public catalogue).
- **The catalogue no longer waits for a source that does not answer.** On 4 October one of the built-in video servers stopped answering; every view of Video, Films or All that was not yet cached waited the full 10 seconds. Now a list from one server has 5 seconds, the others get 1.5 seconds once the first has answered, and a server that fails slowly is skipped for 5 minutes and then asked again in the background. Measured with the server down: first view 10.3 s → 2.1 s, further views 10 s → under 1 s.
- **The catalogue does not jump while loading.** When you changed the category the large introduction panel appeared for a moment and pushed the catalogue down and back up. The layout now stays in place while the catalogue loads.
- **Programs: also the first program in a new launcher folder.** 0.4.50 watches the launcher folders that exist when Safeer OS starts. On a fresh computer some do not exist yet (the first Flatpak program creates one); such a first program appeared only after a restart. It now appears at once as well.

## Packages

- **The packages are installed on real Linux Mint before every release.** The build used to install them on Ubuntu 22.04 only; the two look packages (`safeer-os-tema`, `safeer-cinnamon`) cannot be installed there at all, because `mint-themes` exists only in Linux Mint. A new job installs the very files that go into the release on Linux Mint 22 and 22.3, starts Safeer OS as a normal user and checks that the page is drawn, then removes the packages and checks that nothing is left behind.
- **Faster start and clean removal of the .deb packages.** The .deb packages now compile the Python byte-code when they are installed. A user cannot write into `/usr/lib`, so until now Python compiled every module again at each start of Safeer OS, Safeer Control and the browser (measured for Safeer OS: 0.31 s → 0.14 s for loading the program code on a 2021 laptop; the difference is larger on older computers). The byte-code is removed again before the package is removed or updated: the new Linux Mint test found that `apt remove` left the program folders behind once a program had been run as root. AppImage and Flatpak are unchanged.
- A test of the internet-through-the-phone switch depended on the speed of the build server and failed once; the test was fixed (the product was not affected).

Safeer Control 2.1.49 and Safeer Browser 1.0.93 have no changes of their own apart from the .deb packaging above.
