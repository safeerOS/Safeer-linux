# Safeer Browser for Linux 1.0.67 · Safeer Control 2.1.23 · Safeer OS 0.4.25

- **Update from the tray:** Safeer Control checks safeer.si itself (every few hours) and, when a new version is out, shows "Update …" in its tray menu – one click downloads the packages, verifies them and installs them (the system asks for your password once). For .deb installs.
- **Straight to the button:** the "Available: Safeer OS …" banner on the home screen now lands exactly on the Updates button in Settings.
- **AppImage:** an update replaces the AppImage in place, so your shortcuts keep working.
- Settings: an empty "Quick settings" section (a computer without sound, brightness and Wi-Fi) is no longer shown.

Safeer Browser 1.0.67 has no changes to the browser itself.

Slovensko: Safeer Control ponudi posodobitev tudi v meniju v pladnju (en klik: prenos, preverba, namestitev); pasica na domačem zaslonu pripelje naravnost do gumba Posodobitve; AppImage se zamenja na istem mestu; prazen razdelek Hitre nastavitve se ne kaže.
