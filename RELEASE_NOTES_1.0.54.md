# Safeer Browser for Linux 1.0.54 · Safeer Control 2.1.10 · Safeer OS 0.4.12

**Safeer Link – no double work (Safeer Control 2.1.10)**
- **The Safeer Link window shows each device's capacity:** for every device (this computer included) whether it can help right now, its cores, free memory and disk, battery and hardware video encoding.
- **The same content is never downloaded twice.** When a TV asks for a film that is already fully downloaded on this computer (in Safeer OS or earlier for another device), the computer streams it straight from disk – no new download, no torrent engine started. Completeness is checked piece by piece, not by file size. When there are several computers, the TV picks the one that already has the film.
- The helper torrent engine now stops when Safeer Control exits.
- Translated the *Connect a new device* button in the Safeer Link window.

Safeer Browser 1.0.54 and Safeer OS 0.4.12 have no other changes.
