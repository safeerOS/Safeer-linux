# Safeer Browser for Linux 1.0.85 · Safeer Control 2.1.41 · Safeer OS 0.4.43

## Safeer OS 0.4.43 – the Shield, fixed and finished

This release is about the Shield (DNS filtering for the whole computer). For the first time it was tested against a real systemd-resolved and NetworkManager – two containers that behave like a desktop Linux Mint and its router – and that test found faults that unit tests could not see. They are fixed, and the test now lives in the repository (`tools/scit_lab`) so they cannot come back unnoticed.

**If you used the Shield on Linux, please update.**

- **Turning the Shield off no longer leaves the computer without DNS.** When the Shield was switched off, or Safeer OS was closed with the Shield on, the network was left with no DNS server at all: nothing resolved until the network reconnected or the computer restarted. The Shield now hands the connection back exactly as NetworkManager set it. If an older version left your connection in that state, Safeer OS repairs it when it starts.
- **The Shield really filters.** On many computers systemd-resolved kept asking the router and the Shield – while showing "Running" – received no queries at all. It is now set up so that it is asked first, and a watchdog brings it back within seconds after the network changes (it used to take up to 20 seconds).
- **Short local names keep working.** With the Shield on, names such as `nas` or `printer` stopped resolving, because the search domain from the router was replaced. The Shield no longer touches search domains.
- **The Shield starts with the desktop surface.** When Safeer OS ran as the desktop surface of Safeer Cinnamon, a Shield that was switched on did not start after login.
- **Computers with their own DNS server are left alone.** Where programs do not ask systemd-resolved (Pi-hole, AdGuard Home and similar on the same computer), the Shield cannot filter and would even have bypassed that filter. It now says "Not available" with the reason and does not touch the DNS settings.
- **No password window from the background.** If the permission to set DNS is missing, the Shield says so in Settings instead of asking for a password at login or every few seconds.
- DNS servers announced over IPv6 are used as well.

New in the Shield:

- **Allow a domain.** Next to each recently blocked name there is now "Allow" – for that domain and its subdomains, effective at once. Allowed domains are listed below with "Block again". Allowing a dangerous domain (fake site, malware) takes a second click.
- **Pause for 15 minutes.** When a page does not work, you no longer have to switch the whole Shield off: the pause stops the blocking of ads and trackers and ends by itself. Dangerous sites stay blocked during the pause.

Safeer Browser 1.0.85 and Safeer Control 2.1.41 have no changes of their own (same code, new number).

Slovensko: ta izdaja je posvečena Ščitu (filtriranje DNS za ves računalnik). Prvič je bil preizkušen na pravem systemd-resolved in NetworkManagerju – v dveh vsebnikih, ki se obnašata kot namizni Linux Mint in njegov usmerjevalnik – in ta preizkus je našel napake, ki jih enotni testi niso mogli videti. Popravljene so, preizkus pa je zdaj v repozitoriju (`tools/scit_lab`). **Če na Linuxu uporabljaš Ščit, posodobi.** **Izklop Ščita ne pusti več računalnika brez DNS**: ob izklopu Ščita ali izhodu iz Safeer OS z vklopljenim Ščitom je povezava ostala brez strežnika DNS – nobeno ime se ni razrešilo do ponovne povezave omrežja ali ponovnega zagona. Ščit zdaj povezavo vrne natanko tako, kot jo je nastavil NetworkManager; če jo je starejša različica pustila v tem stanju, jo Safeer OS ob zagonu popravi. **Ščit res filtrira**: na mnogih računalnikih je systemd-resolved še naprej spraševal usmerjevalnik in Ščit – čeprav je kazal »Deluje« – ni dobil nobene poizvedbe; zdaj je vprašan prvi, straža pa ga po menjavi omrežja vrne v nekaj sekundah (prej do 20). **Kratka domača imena delajo**: z vklopljenim Ščitom se imena, kot sta `nas` ali `tiskalnik`, niso več razrešila, ker je bila iskalna domena usmerjevalnika zamenjana; Ščit se iskalnih domen ne dotika več. **Ščit se zažene tudi z delovno površino** (Safeer Cinnamon) – prej se vklopljen Ščit po prijavi tam ni zagnal. **Računalnik z lastnim strežnikom DNS** (Pi-hole, AdGuard Home ipd. na istem računalniku): Ščit tam ne more filtrirati in bi ta filter celo zaobšel; zdaj napiše »Ni na voljo« z razlogom in se nastavitev ne dotakne. **Brez okna za geslo iz ozadja**; uporablja tudi strežnike DNS, oglašene po IPv6. Novo: **Dovoli domeno** – ob vsakem nazadnje blokiranem imenu je »Dovoli« (za domeno in poddomene, velja takoj), dovoljene domene so naštete spodaj z »Blokiraj spet«; za nevarno domeno (lažna stran, zlonamerna koda) je potreben drugi klik. **Premor 15 minut** – ko kakšna stran ne dela, ni treba izklopiti celega Ščita: premor ustavi blokiranje oglasov in sledilcev in se konča sam; nevarne strani ostanejo blokirane. Safeer Browser 1.0.85 in Safeer Control 2.1.41 nimata svojih sprememb.
