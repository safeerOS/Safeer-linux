# Safeer Browser for Linux 1.0.87 · Safeer Control 2.1.43 · Safeer OS 0.4.45

## Safeer OS 0.4.45

- **The first film from a torrent: a visible step, not silent waiting.** To play a film from a torrent, Safeer OS downloads the open-source program rqbit once (about 27 MB, from its official release page, checked against its checksum). Until now this happened silently while the screen said "Preparing …". Now you see what is being downloaded and how far it is, and you can cancel it.
- **A clear message when it does not work.** If the program could not be downloaded (no connection, for example), Safeer OS used to try the next two torrents – downloading the program again each time – and then reported that "the stream is unreachable". It now stops at once and says that the player program could not be downloaded.
- **The Shield is tested against a real system before every release.** The test from 0.4.43 (a real systemd-resolved and NetworkManager in two containers, 42 checks) now runs automatically – once with the code from the repository and once inside the sandbox of the Flatpak package that was just built, with the package's own code. A release cannot be created unless both pass.

Safeer Browser 1.0.87 and Safeer Control 2.1.43 have no changes of their own (same code, new number).

Slovensko: **Prvi film iz torrenta: viden korak, ne tiho čakanje.** Za predvajanje filma iz torrenta Safeer OS enkrat prenese odprtokodni program rqbit (približno 27 MB, z njegove uradne strani izdaj, preverjen s kontrolno vsoto). Doslej se je to zgodilo tiho, medtem ko je na zaslonu pisalo »Pripravljam …«. Zdaj vidiš, kaj se prenaša in koliko je že preneseno, in prenos lahko prekličeš. **Jasno sporočilo, kadar ne gre.** Če programa ni bilo mogoče prenesti (na primer brez povezave), je Safeer OS poskusil še z naslednjima torrentoma – in program vsakič prenašal znova – ter nato sporočil, da »tok ni dosegljiv«. Zdaj se ustavi takoj in pove, da predvajalnega programa ni bilo mogoče prenesti. **Ščit je pred vsako izdajo preizkušen na pravem sistemu.** Preizkus iz 0.4.43 (pravi systemd-resolved in NetworkManager v dveh vsebnikih, 42 preverb) zdaj teče samodejno – enkrat s kodo iz repozitorija in enkrat v peskovniku pravkar zgrajenega paketa Flatpak, z njegovo kodo. Brez obeh zelenih izdaja ne more nastati. Safeer Browser 1.0.87 in Safeer Control 2.1.43 nimata svojih sprememb.
