# Safeer Linux: encrypted unreleased work

This branch holds one file, `zaupno/izdaja-linux-1411.tar.gpg`: unreleased Safeer Linux work packed as a git bundle and
encrypted with the public key in the build repository (`zaupno/kljuc.pub.asc`). It is decrypted only by the build runner
(repository secret) or by the project lead. It contains no plaintext source. The content is published normally, after review
and release, on the regular branches.
