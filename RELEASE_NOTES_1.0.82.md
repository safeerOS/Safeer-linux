# Safeer Browser for Linux 1.0.82 · Safeer Control 2.1.38 · Safeer OS 0.4.40 · Safeer Cinnamon 1.2.1

## Safeer OS 0.4.40 – Files on the workspace work like a file manager

- **Select several files.** A click selects one file, Ctrl+click adds or removes one, Shift+click (or Shift+arrow) selects a range and Ctrl+A selects everything in the folder. Below the list you see how many items are selected and how large they are. Copy, Cut, Move to Trash, the Delete key and Restore (in the Trash) act on the whole selection, and the right-click menu shows the count.
- **Drag and drop.** Drag the selected files onto a folder – in the list or in the sidebar – to move them there; hold Ctrl to copy them instead. Files you drag in from another program (Nemo) are copied into the folder you drop them on. Files you drag out of Files go to other programs as ordinary files: Nemo copies them (hold Shift to move).
- **Notifications are visible again.** Messages such as "Copied" or "Moved to Trash" were drawn at the very bottom of the screen, behind the dock. They now appear above it.
- Dragging files no longer highlights a whole column as if a panel were being moved, and a panel title is no longer selected as text while you drag it.

## Safeer Cinnamon 1.2.1

- **HiDPI screens.** The dock icon size is now worked out from the logical height of the screen (a 4K screen at 200 % counts as 1080 points), so the dock no longer gets the largest icons there.
- **"Larger text" returns your own size.** If you already used larger text before turning Safeer Cinnamon on (for example 150 %), the Larger text switch goes back to that size instead of 125 %. `safeer-cinnamon --vecji-tekst` without a number does the same.

Safeer Browser 1.0.82 and Safeer Control 2.1.38 have no changes of their own (same code, new number).
