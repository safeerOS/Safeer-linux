# Safeer Browser for Linux 1.0.51 · Safeer Control 2.1.7 · Safeer OS 0.4.9 · Safeer Cinnamon 1.0.0

**Safeer Link (Safeer Control 2.1.7)**
- **Pairing with the 6-digit code works on every computer.** On a computer that hosts its own Safeer Link, *Connect devices* now shows the QR code *and* the 6-digit code, and the computer no longer waits for "your approval" or tries to pair with itself. The QR code carries the computer's home network address (it pointed to 127.0.0.1 before).
- The code is valid only while you see it: closing the window cancels it, so a code you type on another device always reaches the device that shows it.

**Safeer OS 0.4.9**
- **Files:** right click (or the + button) creates a new folder or file – empty, text, document, spreadsheet, presentation or one of your templates – and you choose where with *Change …*. Right click on a file offers *Rename* (F2) and *Move to Trash* (Delete). Nothing is ever overwritten or deleted for good.

**New: Safeer Cinnamon 1.0.0 (optional, Linux Mint)**
- A calm, semi-transparent dark blue look for Cinnamon (based on CBlue, built on Mint-Y), three Safeer wallpapers, a Plank dock and a desktop workspace: search for the web, apps, files and media, a media panel, files from all your devices and apps on your devices. Turn it on from the menu (*Safeer Cinnamon*); *Restore previous look* puts everything back exactly as it was. Package: `safeer-cinnamon_1.0.0_all.deb` (GPL-3.0).

Safeer Browser 1.0.51 has no changes to the browser itself.

Slovensko: **Safeer Link:** povezovanje s 6-mestno kodo deluje na vsakem računalniku – okno *Poveži naprave* pokaže QR kodo in 6-mestno kodo, QR nosi domači naslov računalnika, koda velja le, dokler je okno odprto. **Datoteke:** desni klik ali gumb + ustvari novo mapo ali datoteko (prazna, besedilo, dokument, preglednica, predstavitev, predloga) v mapi po izbiri; preimenuj (F2) in premakni v Smeti (Delete). **Novo: Safeer Cinnamon 1.0.0** – izbirni modri polprosojni videz za Linux Mint z delovno površino (iskanje, mediji, datoteke vseh naprav, programi naprav), tremi ozadji in dockom; vklop v meniju, *Vrni prejšnji videz* povrne vse.
