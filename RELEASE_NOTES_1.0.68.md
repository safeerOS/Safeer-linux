# Safeer Browser for Linux 1.0.68 · Safeer Control 2.1.24 · Safeer OS 0.4.26

- **Your start page, your shortcuts:** on the Web start page, "Edit shortcuts" (or right-click a shortcut) lets you remove any shortcut – built-in ones too – and "Restore defaults" brings them back. Nothing is forced on you.
- **Update from the tray:** Safeer Control checks safeer.si itself and, when a new version is out, shows "Update …" in its tray menu – one click downloads, verifies and installs the packages (.deb installs; the system asks for your password once).
- **Straight to the button:** the "Available: Safeer OS …" banner on the home screen lands exactly on the Updates button in Settings.
- **AppImage:** an update replaces the AppImage in place, so your shortcuts keep working.
- Settings: an empty "Quick settings" section is no longer shown.

Safeer Browser 1.0.68 has no changes to the browser itself besides the start page.
