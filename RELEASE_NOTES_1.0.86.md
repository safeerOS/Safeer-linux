# Safeer Browser for Linux 1.0.86 · Safeer Control 2.1.42 · Safeer OS 0.4.44

## Safeer OS 0.4.44

- **Open with … in Files.** On the desktop surface, right-click a file or a folder and choose "Open with …": you get the programs that registered for that type of file – the same list as in the file manager – with the default one first. "Another program …" shows every program in the menu that can open a file. Tick "Always open this type of file with this program" and the chosen program becomes the default for the whole desktop, not only for Safeer OS. It works for several selected files at once.
- **The Shield in the Flatpak package.** In the Flatpak the Shield could not be switched on: it asked for the password and then reported an error, because the permission rule was written to a temporary folder that the system outside the sandbox cannot see. It now works there, and it also reads the computer's real DNS settings instead of the delayed copy inside the sandbox. Like the rest of the Shield, this is now tested in a real Flatpak sandbox (`tools/scit_lab`, 42 checks, in both modes).

Safeer Browser 1.0.86 and Safeer Control 2.1.42 have no changes of their own (same code, new number).

Slovensko: **»Odpri z …« v Datotekah.** Na delovni površini z desnim klikom na datoteko ali mapo izbereš »Odpri z …«: dobiš programe, ki so se prijavili za to vrsto datotek – isti seznam kot v upravitelju datotek – s privzetim na prvem mestu. »Drug program …« pokaže vse programe iz menija, ki znajo odpreti datoteko. S kljukico »Vedno odpri to vrsto datotek s tem programom« izbrani program postane privzeti za vse namizje, ne samo za Safeer OS. Deluje tudi za več izbranih datotek hkrati. **Ščit v paketu Flatpak.** V Flatpaku Ščita ni bilo mogoče vklopiti: vprašal je za geslo in nato javil napako, ker je pravilo dovoljenja zapisal v začasno mapo, ki je sistem zunaj peskovnika ne vidi. Zdaj tam deluje in bere prave nastavitve DNS računalnika namesto zakasnjene kopije v peskovniku. Kot ves Ščit je tudi to zdaj preizkušeno v pravem peskovniku Flatpak (`tools/scit_lab`, 42 preverb, v obeh načinih). Safeer Browser 1.0.86 in Safeer Control 2.1.42 nimata svojih sprememb.
